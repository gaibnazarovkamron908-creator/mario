# Mario Run — браузерная игра

Готовый статический проект для публикации через GitHub Pages.

## Публикация

1. Создайте новый публичный репозиторий на GitHub.
2. Загрузите в корень репозитория все файлы из этой папки.
3. Откройте `Settings` → `Pages`.
4. В разделе `Build and deployment` выберите `Deploy from a branch`.
5. Выберите ветку `main`, папку `/ (root)` и нажмите `Save`.

После публикации игра будет доступна по адресу:

`https://ВАШ-ЛОГИН.github.io/НАЗВАНИЕ-РЕПОЗИТОРИЯ/`

Сборка и установка зависимостей не требуются: вся игра находится в `index.html`.
